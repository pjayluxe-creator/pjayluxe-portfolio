# P_JAY LUXE Website

A responsive business website for P_JAY LUXE, showcasing professional plumbing services and 3D flooring designs.

## Built with
- HTML5
- CSS3 (embedded in `index.html`)
- JavaScript: no separate JavaScript file is included in this version.

## Preview locally
Keep `index.html` and all image files in the same folder, then open `index.html` in a browser.

## Deployment
This is a static website and can be deployed with Netlify or GitHub Pages.
